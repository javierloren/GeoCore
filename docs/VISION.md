# GeoCore Vision

## Why GeoCore Exists

Commercial geotechnical software is powerful, but access is uneven. Students,
universities, public institutions, and small consultants often cannot afford the
licenses needed for normal professional workflows: borehole logging, core photo
analysis, RQD, rock mass classification, laboratory integration, maps, cross
sections, reports, and engineering checks.

GeoCore exists to reduce that barrier.

The goal is not only to create calculators. The goal is to create a coherent
workspace where geotechnical data can be entered, reviewed, interpreted,
calculated, visualized, exported, and reported.

## Positioning

GeoCore should compete first with workflows from:

- RSLog.
- LogPlot.
- gINT / OpenGround.
- HoleBASE.
- RockWorks.
- Leapfrog Works, for simpler borehole and section workflows.

Later modules can approach selected workflows from:

- Rocscience slope and rock mechanics tools.
- SSAP-style slope stability.
- PLAXIS-style analysis only if the project eventually has the technical base
  and validation discipline to do it responsibly.

## Product Promise

GeoCore should let a user complete a real investigation workflow:

1. Create a project.
2. Add boreholes and coordinates.
3. Enter soil and rock logs.
4. Upload core box photographs.
5. Calculate and review core recovery and RQD.
6. Add samples, SPT/CPT, groundwater, and laboratory data.
7. Generate borehole logs.
8. Generate project reports.
9. Export data in open formats.

## Design Principles

- Free for everyone.
- Open source by default.
- Transparent calculations.
- Useful offline or self-hosted.
- Professional reports, not toy outputs.
- Modular architecture.
- AI-assisted, never AI-authoritative.
- International by design, with English and Spanish as initial languages.
- Built for students and professionals, not only developers.
