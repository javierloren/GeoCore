# Contributing to GeoCore

GeoCore is intended to become a public open-source geotechnical engineering
suite. Contributions should improve professional usefulness, transparency, and
accessibility.

## Priorities

1. Correct calculations.
2. Clear data structures.
3. Professional reports.
4. Simple workflows.
5. Good tests for engineering logic.

## Engineering Rules

- Keep calculations outside the Streamlit UI.
- Add tests for non-trivial engineering logic.
- Prefer open formats.
- Avoid hidden assumptions.
- Document formulas and references.
- Do not present unvalidated methods as design-grade engineering tools.

## Safety

GeoCore can assist engineering work, but users remain responsible for checking
inputs, assumptions, local codes, and professional judgement.
